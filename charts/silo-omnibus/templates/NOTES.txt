  kubectl --namespace {{ .Release.Namespace }} create secret generic {{ include "silo-omnibus.secretKeySecretName" . }} \
    --from-literal {{ .Values.secretKey.secretKey }}="$(openssl rand -base64 48)"

  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "silo-omnibus.fullname" . }} 8080:{{ .Values.service.port }}

Open it to finish first-run setup. The Jellyfin-compatible API is on port {{ .Values.ports.jellyfin }} and Audiobookshelf on {{ .Values.ports.audiobookshelf }} of the same Service.
